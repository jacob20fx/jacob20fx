SYSTEM NDA: Stripe Payment Link -> NDA -> Discord
=================================================

WAŻNE:
- Nie zmieniono index.html, app.js, admin.js ani obecnego formularza.
- Nowy system działa w osobnych plikach: nda.html, nda.js, nda-style.css oraz /api.
- Nie wpisuj klucza Stripe, SERVICE ROLE KEY ani linku Discord do plików na GitHubie.

KROK 1 — SUPABASE
1. Otwórz Supabase -> SQL Editor -> New query.
2. Z pliku supabase-setup.sql skopiuj część zaczynającą się od:
   -- NDA PO PŁATNOŚCI STRIPE
3. Kliknij Run.

KROK 2 — VERCEL ENVIRONMENT VARIABLES
Vercel -> projekt -> Settings -> Environment Variables. Dodaj:

STRIPE_SECRET_KEY
- Tajny klucz Stripe zaczynający się od sk_live_ albo sk_test_.

STRIPE_PAYMENT_LINK_ID
- ID używanego Payment Linku, zwykle zaczyna się od plink_.
- Pole opcjonalne, ale mocno zalecane: blokuje użycie płatności z innego linku.

SUPABASE_URL
- Project URL z Supabase.

SUPABASE_SERVICE_ROLE_KEY
- Klucz service_role z Supabase.
- To klucz tajny. Nigdy nie umieszczaj go w config.js ani na GitHubie.

DISCORD_INVITE_URL
- Pełny link zaproszenia do prywatnego Discorda.
- Najlepiej utwórz zaproszenie z ograniczeniem użyć lub okresu ważności.

Zaznacz środowiska Production, Preview i Development albo przynajmniej Preview na czas testów.
Po dodaniu zmiennych wykonaj Redeploy.

KROK 3 — STRIPE PAYMENT LINK
Stripe -> Payment Links -> wybierz link -> Edit -> After payment:
1. Zaznacz "Don't show confirmation page".
2. Wpisz dokładnie:
   https://TWOJA-DOMENA.vercel.app/nda?session_id={CHECKOUT_SESSION_ID}

Przykład dla obecnej domeny:
   https://jacob20fx.vercel.app/nda?session_id={CHECKOUT_SESSION_ID}

Nie zastępuj ręcznie tekstu {CHECKOUT_SESSION_ID}. Stripe zrobi to automatycznie.

KROK 4 — TEST
Najpierw korzystaj z trybu testowego Stripe oraz klucza sk_test_.
Wykonaj płatność testową i sprawdź:
- przekierowanie na /nda,
- pobranie e-maila ze Stripe,
- zapis rekordu w Supabase -> Table Editor -> nda_signatures,
- pokazanie przycisku Discord dopiero po podpisaniu.

KROK 5 — WDROŻENIE GAŁĘZI
Najpierw przetestuj Preview Deployment gałęzi nda-system.
Dopiero po poprawnym teście połącz nda-system z main.

UWAGA PRAWNA
Treść NDA jest szablonem technicznym, a nie indywidualną poradą prawną. Przed sprzedażą na większą skalę uzupełnij pełne dane Administratora i skonsultuj treść, zasady przetwarzania danych oraz okres przechowywania podpisów z prawnikiem.
